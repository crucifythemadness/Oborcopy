Third-party software: Qt
========================

This package contains libraries of the Qt framework (https://www.qt.io),
Copyright (C) The Qt Company Ltd. and other contributors.

Qt is used under the terms of the GNU Lesser General Public License
version 3 (LGPL v3): https://www.gnu.org/licenses/lgpl-3.0.html

The Qt libraries are linked dynamically and shipped as separate files
(Windows: Qt6*.dll, Linux: lib/libQt6*.so*). You may replace them with
other, compatible builds of Qt. The Qt source code is available from
https://download.qt.io/official_releases/qt/ .

Windows packages additionally contain the GCC/MinGW runtime libraries
(libgcc_s_seh-1.dll, libstdc++-6.dll, libwinpthread-1.dll), which are
distributed under the GCC Runtime Library Exception / MIT-style licenses.

Linux packages additionally contain shared libraries from Ubuntu 24.04
(e.g. ICU, PCRE2, double-conversion, xcb-util), each under its own
open-source license; see https://packages.ubuntu.com for details.
